## Structure

Assets are organized by type under /assets/:

- assets/images/  — pictures (image-<id>.<ext>)
- assets/fonts/   — webfonts (font-<id>.<ext>)
- assets/videos/  — video files
- assets/audio/   — audio files
- assets/css/     — stylesheets
- assets/animate/ — JavaScript modules & runtime data (original names kept — module imports depend on them)
- assets/meta/    — files referenced from <meta> tags (social preview images, search indexes)
- assets/files/   — everything else
